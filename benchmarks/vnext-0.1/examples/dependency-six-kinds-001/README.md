# Six dependency kinds: native diagnostic archive

Three actual traces establish all six supported dependency types. These are
native protocol/Reference diagnostics, not real-model performance or a release
dataset. The cross-turn trace demonstrates cancellation of a previously accepted
lesson after an actual later Customer choice. The mixed refund trace binds the
completed refund to a later accurately refused duplicate. The Property trace
binds physical work to a later legal closure. Previous source artifacts remain
unchanged; the two reused native traces have newly computed diagnostic proofs.

Run `PYTHONPATH=. .venv/bin/python <absolute path to this folder>/verify.py` from
the exact source checkout. For a later checkout, extract `source-snapshot.zip`
into an empty directory and run the script using that directory as working
directory and `PYTHONPATH` with the project's Python/dependencies. Source pin,
world generation, Oracle, actual Replay, canonical proof list and each independent
Reference dependency must all match. No model API is contacted.
