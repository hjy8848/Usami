01 / THE QUESTION

如果测试者也能学习，
下一道题会是什么？

固定题库能衡量一次能力，却很难持续揭示一个交互式 Agent 的边界。一次看似简单的“启动服务器”，可能同时依赖项目状态、成员权限、资源配额和上游服务。

我们的研究问题是：Customer 能否学会提出更有价值的挑战，Service 能否从这些挑战中学会更可靠的决策？ Usami 提供可执行环境；VAST-CoEvo 在其上研究双方声明式 Skill 的迭代，基础模型权重保持冻结。

02 / THE RECURSIVE LOOP

先交互，再学习。

每一代共享已验证的训练交互，下一代加载实际选中的版本。

CURRENT PROTOCOL · v3
CUSTOMER

静态合法，即可更新版本。

保留 Schema、版本、作用域与安全约束。性能诊断只用于研究分析，不决定选中版本；静态接受不代表能力提高。

SERVICE

静态与动态验收，缺一不可。

检验已知错误修复、合法业务完成、正确拒绝和授权异常。未通过验收继续使用旧版，不能靠一律拒绝获得提升。

TRAIN ≠ EVALUATE

四组交叉测试已移出训练主循环。训练后可加载任意已保存版本独立比较；Frozen Held-out 不参与 Reflection 或候选选择。
